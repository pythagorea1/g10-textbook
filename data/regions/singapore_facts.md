1. **マラッカ海峡チョークポイント依存**
   - 背景: 世界最繁忙の海峡。年10万隻超、原油≈23.2 mb/d(海上原油の約29%)、貿易額≈$3.5兆(世界GDPの1/3相当)が通過。シンガポール港(PSA)は世界最大級の積替えハブ。
   - 波及経路: 海峡封鎖・紛争・海賊・事故 → 中継貿易量と港湾収入の直撃 → 燃料・食料輸入コスト上昇 → 成長・インフレへ。
   - 関連国: 中国(輸入原油の8割超が通過＝"マラッカ・ジレンマ")、インドネシア、マレーシア、米国(2026年に米・インドネシア防衛協定で影響力拡大)、インド。**[接続: 新規 malacca/南シナ海イベント]**

2. **米中対立の最前線・バランシング**
   - 背景: 中立的金融ハブとして米中双方が影響力を競う。半導体・AIの技術デカップリング、対中輸出規制、サプライチェーン再編。
   - 波及経路: 二者択一圧力 → 再輸出規制・ドル決済リスク → 多国籍企業の地域HQ立地判断 → 直接投資・金融フロー。
   - 関連国: 米国、中国、ASEAN。**[接続: `us_china_trade_2018`, `china_shock_2015`, `trump_tariff_2025`]**

3. **香港代替地としての地位上昇(と裏リスク)**
   - 背景: 2020年香港国家安全法以降、UHNW・ファミリーオフィス・資産運用がシンガポールへ移転。MAS税制優遇(13O/13U、2029年まで延長)とVCC制度が後押し。2023年時点で香港・シンガポールとも約$1.3兆のオフショア資産を運用(スイス$2.5兆に次ぐ)。
   - 波及経路: 資本流入で資産価格・不動産・通貨を押上げ。一方で中国系資金への依存と監視強化(2023年S$30億マネロン事件)。
   - 関連国: 香港、中国、スイス。**[接続: 新規 hk_capital_flight / china_property]**

4. **都市国家の構造的脆弱性(食料・水・エネルギー)**
   - 背景: 食料の **90%超を輸入**(国土の1%のみ農地)、水はマレーシアに依存(2060年自給目標、NEWater・淡水化で代替=電力多消費)、エネルギーはほぼ全量輸入(発電は天然ガス中心)。
   - 波及経路: 供給ショック・対馬来関係悪化 → 物価・電力料金 → コアインフレ(住居・交通除く)と家計。
   - 関連国: マレーシア(水・食料・JS-SEZ)、インドネシア、豪州(食料)、中東(LNG/原油)。

5. **ホルムズ海峡・中東エネルギー連鎖**
   - 背景: 輸入原油・LNGの多くがホルムズ→マラッカ経由。2024-2026年の中東/イラン情勢緊迫が燃料輸入価格を押上げ、**2026年のインフレ見通し上方修正の直接要因**に。
   - 波及経路: ホルムズ緊張 → 原油・ガス・運賃上昇 → 輸入コスト全般 → MASのスロープ引上げ(2026/4)。
   - 関連国: イラン、湾岸産油国、米国。**[接続: `middle_east_2024`、新規 hormuz イベント]**

6. **南シナ海・ASEAN中立と航行の自由**
   - 背景: 領有権紛争の当事国ではないが、開かれたシーレーンに死活的に依存。ASEANの結束維持に注力。
   - 波及経路: SCSでの衝突・航行制限 → 海運保険料・迂回コスト → 中継貿易。
   - 関連国: 中国、フィリピン、ベトナム、米国。

7. **地域安全保障と米軍プレゼンス**
   - 背景: チャンギ海軍基地が米海軍のロジ拠点。米国との防衛協力、英・豪・馬・NZとの五カ国防衛取極(FPDA)。
   - 波及経路: 大国間緊張の高まり → 安全保障コスト・地政学プレミアム → 投資家のリスク認識。
   - 関連国: 米国、英国、豪州、マレーシア、NZ。

8. **ジョホール・シンガポール経済特区(JS-SEZ)とマレーシア統合**
   - 背景: 2025年に枠組み合意。労働・用地・製造をマレーシア側に拡張する機会だが、依存も深化。
   - 波及経路: 統合進展 → コスト競争力・サプライチェーン強靭化 / 二国間政治リスク。
   - 関連国: マレーシア。

## 6. 章ごとのメモ (01-21)

- **01 中央銀行**: MASは「中央銀行＋統合金融規制＋準備金運用」を一体で担う世界的にも特異な機関(1971設立、2002にBCCS統合)。利下げ/利上げ会合ではなく**半年ごとのMonetary Policy Statement(MPS)**が主役。
- **02 政策金利 → 翻案「為替ベース金融政策」**: 本章は **政策金利が存在しない**点が核心。S$NEER政策バンド(スロープ=appreciation率／幅width／中心centre)で運営。国内金利(SORA)は内生的(不完全な金利平価＋資本移動)。1981年枠組み採用、緩和=スロープ縮小/ゼロ/再センター下げ、引締め=スロープ急傾斜/再センター上げ、で説明。直近: 2025/1緩和→2026/4やや引締め。
- **03 財政政策**: 憲法上の任期内均衡規律、巨額の準備金(MAS/GIC/Temasek)、**NIRC**が歳出の約20%(FY2026≈S$28.5bn)。GST段階引上げ(→9%、2024)。一貫した財政黒字(Budget2025黒字≈S$6.8bn)。SGSは資金調達目的でなく市場育成目的=「ネット政府債務ゼロ」の論点。
- **04 雇用**: 完全雇用に近い低失業(Q1'26 2.1%)、外国人労働力依存、**CPF**(強制積立)、生産性課題、リテンチメントは構造改革主因。
- **05 インフレ**: **MAS Core(住居費・自家用車費を除く)**が政策の主指標。2022ピーク(総合6.1%/コア4.1%)、GST影響、2025低下、2026エネルギー由来で再上昇。
- **06 株式市場概観**: SGX、STI30銘柄、銀行3行(DBS/OCBC/UOB)とREITの高比重、アジアのREITハブ、二重上場。
- **07 株式(初期)**: マラヤ証券取引所→1973年KL/シンガポール分離、SES時代、1998年CLOB問題(対馬来株決済凍結)。
- **08 株式(近代)**: 1999年SGX発足(SES＋SIMEX合併・株式会社化)、デリバティブ強み(SIMEXは1984年アジア初の金融先物取引所)。
- **09 株式(現代)**: 2007ピーク3,906→GFCで1,457、その後のREIT市場拡大、海外企業の二次上場。
- **10 株式(現在)**: 2026年STI 5,000突破→史上最高値≈5,072。銀行・配当・AI需要が牽引。一方で**上場社数の減少・新規上場の枯渇**が課題で、MASがS$50億規模の株式市場活性化プログラムを始動。
- **11 債券市場**: SGS(AAA)、MAS Bills、シンガポール貯蓄債券(SSB)。発行は資金調達でなくベンチマーク/市場育成目的。アジア・ダラー債市場の拠点。
- **12 短期金利**: **SORA**が唯一の主要ベンチマーク(SIBOR/SORは2024/1廃止)。金利は為替政策＋グローバル金利で内生的に決定。MAS Billsで流動性調節。
- **13 長期金利**: SGS 10年≈2.0-2.1%(2026/6)、AAA。米国債に概ね連動＋スプレッド。CPF・保険の需要が需給を支える。
- **14 通貨**: SGD、管理フロート(NEERバンド)。1967発行・ブルネイと1:1交換性、1973フロート、1981 NEER枠組み。闇レートなし(完全交換性)。
- **15 危機**: §4年表を流用。1985リセッション/1997-98アジア危機/2003 SARS/2008 GFC/2020 COVID/2023マネロン事件。
- **16 銀行制度**: 地場3行(DBS・OCBC・UOB)は高資本・地域大手。MASの統合監督、アジア・ダラー市場(ACU)、デジタルバンク認可。世界トップクラスの国際金融センター。
- **17 企業・コーポレート**: テマセク系GLC(Singtel・Keppel・SIA等)、REIT群、多国籍企業の地域統括拠点(RHQ)集積。
- **18 規制**: MASは統合規制当局。2023年マネロン事件後のAML/CFT厳格化、**VCC**ファンド制度、ファミリーオフィス税制(13O/13U)、決済サービス法(PSA)による暗号資産/フィンテック免許。
- **19 貿易**: 中継貿易立国、貿易/GDP比 300%超、世界最大級の積替え港(PSA)、FTA網(CPTPP・RCEP)、電子・医薬・石油化学が主力輸出。米中関税(2018/2025)の影響を受けやすい。
- **20 教訓**: 小国開放経済のレジリエンス、準備金=ショック吸収バッファ、為替ベース金融政策の有効性と限界、産業多様化、外国人材、脆弱性(食料・水・エネルギー)管理。
- **21 地政学リスク(新設)**: §5を中核に。マラッカ海峡/米中バランシング/香港代替地/都市国家脆弱性/ホルムズ・中東/南シナ海/米軍プレゼンス/JS-SEZ。`geopolitical_events.js`の既存イベントにSGを追記し、新規でマラッカ・香港資本移動イベントを追加検討。

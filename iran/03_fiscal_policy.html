🇮🇷 イラン③ 財政政策

イランの財政を一言で表せば、「制裁で削られる石油収入に依存し、足りない分を中央銀行に刷らせて埋める」構造である。歳入の約45%を石油が占めるため、油価・輸出量・制裁の強度に予算が大きく揺さぶられる。不足分を国債の市場消化でなく中央銀行のファイナンス（貨幣化）で賄うため、財政赤字が直接インフレに転化する。本章では、石油依存・補助金・中銀ファイナンスという3つの構造的弱点を整理する[1]。

歳入の柱 — 石油・税・そして「足りない分」

イランの国家予算は、大きく①石油・ガス収入、②税収、③その他（国有企業配当・関税等）から成る。歴史的に石油収入が最大の柱で、予算の約45%を占めるとされる。だが石油収入は制裁の強度に直撃される。2012年のEU石油禁輸とSWIFT遮断、2018年の制裁再発動で輸出は激減し、その都度、財政は深刻な穴を抱えた[2]。

それでもイランは完全に干上がってはいない。中国がイラン原油の約9割を「影の船団（ダークフリート）」経由で購入し続けており、制裁下でも年間およそ310億ドルの石油収入を確保していると推計される（19・21章で詳述）。とはいえ、これは制裁前の水準を大きく下回り、しかも油価と中国の購買意欲に左右されるため、歳入の不安定さは構造的である。

歳入源性格リスク要因
石油・ガス収入予算の約45%。最大の柱制裁・油価・輸出量に直撃される
税収制裁下で重要性が増す安定財源非公式経済が大きく捕捉率が低い
国有企業・bonyad配当宗教財団・IRGC系を含む不透明、財政外の資金循環
中銀ファイナンス（穴埋め）赤字の貨幣化直接インフレに転化

財政赤字の「貨幣化」 — なぜ赤字がそのままインフレになるのか

先進国では、財政赤字は国債を発行して市場（投資家・銀行）に消化させるのが基本だ。しかしイランは、国際資本市場へのアクセスが制裁で断たれ、国内の債券市場も小さい（11章）。このため、歳出が歳入を上回ったとき、政府はしばしば中央銀行に資金を供給させて穴を埋める。これは実質的に「お金を刷って財政を賄う」貨幣化（マネタイゼーション）であり、マネーサプライの膨張を通じて直接インフレを押し上げる[3]。

この「財政赤字 → 中銀ファイナンス → マネー膨張 → インフレ → 通貨安 → 輸入物価上昇 → さらに財政悪化」という悪循環こそ、イランが40%超の慢性高インフレから抜け出せない最大の構造的理由である。金利政策（02章）でインフレを抑えられないため、財政規律と為替の安定がなければ物価は鎮まらない。

🧠
イラン財政の悪循環ループ
制裁で石油収入↓ → 財政赤字 → 中銀が刷って穴埋め → マネー膨張 → インフレ40%超 → リアル安 → 輸入コスト↑ → 財政さらに悪化。この輪を断つには制裁緩和か財政規律が要るが、どちらも難しい。だから高インフレが「常態」になる。

補助金という重荷 — 燃料・パンと「現金給付」の綱引き

イラン財政のもう一つの特徴が、巨額の補助金である。産油国でありながら、ガソリン・燃料・パンなどの生活必需品を政府が安く供給し続けてきた。とりわけ燃料補助金は規模が大きく、安価なガソリンは国内消費と密輸を助長し、財政を圧迫してきた[4]。

歴代政権は補助金改革（価格の引き上げと現金給付への置き換え）を試みてきたが、これは政治的に極めて危険だ。2019年11月のガソリン値上げは全国的な抗議運動の引き金となり、多数の死傷者を出した。生活必需品の補助金を削れば民衆の怒りを買い、削らなければ財政が持たない——この「補助金のジレンマ」が、イランの財政運営を慢性的に縛っている。

歳出項目内容論点
燃料・食料補助金ガソリン・パン等を安価に供給削減は抗議運動を誘発（2019年）
現金給付補助金改革に伴う直接給付インフレで実質価値が目減り
国防・安全保障IRGC・地域プレゼンス・戦費2025-26年の戦争で急増
公的部門人件費大きな公務員・国有企業セクター賃金がインフレに追いつかない

2026年 — 戦時財政の試練

2025〜2026年の戦争（12日間戦争・2026 Iran war）は、イラン財政に二重の打撃を与えている。一方で、国防・戦費の急増が歳出を押し上げ、他方で、戦闘とホルムズ海峡をめぐる緊張が石油輸出と歳入を脅かす。世界銀行は2025年の実質成長率を-1.7%と推計し（IMFは+0.6%と乖離）、2026年はさらに悪化が見込まれる[5]。

戦時下で歳入が細る一方、歳出が膨らめば、赤字を中銀ファイナンスで埋める誘惑はさらに強まる。これがインフレ（CBI報告で前年比65.8%）と通貨崩壊（1ドル約180万リアル）を加速させる。イランの財政は、制裁・戦争・補助金・中銀ファイナンスという複数の重荷を同時に背負った、極めて脆弱な状態にある。財政の持続可能性こそ、イラン経済の最大の弱点である。

「資源依存の罠」 — 産油国なのに豊かになれない

イラン財政の根底にあるのは、典型的な「資源の呪い（resource curse）」である。豊富な石油・ガスを持ちながら、その収入が①政治的レント（既得権・腐敗）の源泉となり、②非石油部門の競争力を削ぎ（オランダ病的な構造）、③予算を油価と制裁という外部要因に人質に取る——この三重の罠が、産油国でありながら持続的な繁栄を阻んできた[6]。

とりわけ問題なのは、財政が「油価が一定以上でないと均衡しない」体質になっている点だ。歳出が石油収入を前提に膨らんでいるため、油価下落や輸出減があると、たちまち赤字が拡大し、中銀ファイナンス（貨幣化）に頼らざるを得なくなる。石油という「祝福」が、財政規律を緩め、インフレと通貨安を招く「呪い」に転じているのである。

石油依存がもたらす歪みメカニズム
歳入の不安定化油価・輸出量・制裁強度で予算が乱高下
非石油産業の弱体化レント依存で製造業・農業の競争力が育ちにくい
財政規律の緩み石油収入を前提に歳出が膨張、赤字の常態化
レント・腐敗石油収入の配分をめぐる既得権益・不透明な資金循環
🧠
イラン財政＝「石油の祝福と呪い」
石油は歳入の約45%を支える「祝福」。だが①油価・制裁で歳入が乱高下、②非石油産業が育たない、③赤字を中銀が刷って埋める。結果、産油国なのにインフレ40%超・通貨崩壊。「資源の呪い」と「制裁」が重なった、世界でも極端な財政脆弱性。

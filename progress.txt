## 2026-04-10 — Task 0.1: chart-builder.js Upgrade (Phase 0)
- Upgraded `expandSeries()` to support `step` parameter (e.g., `step: 1/12` for monthly data)
  - Backward compatible: defaults to `step: 1` (annual) when not specified
- Added new `ChartBuilder.spread(id, cfg)` public API for yield spread charts
  - Accepts `long` and `short` series, auto-computes difference (long - short)
  - Draws zero line (white dashed)
  - Positive spread area filled green/teal (rgba 0,212,170,0.25)
  - Negative spread area (inverted yield curve) filled red (rgba 255,107,107,0.35)
  - Uses SVG clipPath for clean positive/negative area separation
  - Legend shows spread name with positive/inverted color indicators
  - Robust month-key alignment (Math.round(year * 12)) for float-safe matching
- Improved `renderLegend()`: extracted to shared function, supports multi-row wrapping for 10+ series
- Added `xAxisStep()` helper: smarter x-axis label spacing for different time spans (1-80+ years)
- Extended COLORS array from 8 to 10 entries for G10 comparisons
- All existing APIs (`lines`, `compound`) remain fully backward compatible
